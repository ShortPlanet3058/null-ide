Null

A calm code editor.

Download Null

macOS · Windows · Linux · Free to use

Most editors fill the screen with panels, badges, pop-ups and bots. Null gives it back: your code, and a blinking cursor. Everything else waits, one keystroke away.

What it does

Everything an IDE does.
Out of sight until you need it.

01

Calm.

The tabs, the files and the status step back while you type, and come back the moment you reach for them.

02

Fast.

Native, and drawn on the GPU. Any file of a big project is a keystroke away, every command and setting another.

03

Precise.

Many cursors, one edit. Rename everywhere, jump to a definition, see the problems: language servers for Rust, Python, TypeScript, Go, C and more, installed in one click.

04

Run.

The terminal is one key away. Run the test under the cursor or any task, and debug with the values shown right in the code.

05

Commit.

Git, built in: commit whole files or parts of them, read the history, switch branches, settle conflicts in place.

06

Write.

Markdown with its preview beside it: tables, formulas and diagrams. And unsaved work survives a crash.

AI

When you ask.
Nowhere when you don't.

  • Off until you turn it on. No panel opening by itself, no suggestion you didn't want.
  • Every change shown first. Written into the code as a diff you keep or undo, one part at a time.
  • Your choice of model. Your Claude or ChatGPT plan, an API key (several are free), or a model that never leaves your computer.
