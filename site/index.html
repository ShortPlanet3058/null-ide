Null in 42 seconds

An editor that starts with nothing, and gives the screen back to your code.

Why Null

An editor that gets out of the way, and stays fast while doing everything an IDE should.

Your code first

One quiet window, a true-black theme (and five others), bars that fade while you type.

Fast

Native and drawn on the GPU: it opens at once, big files and big projects included.

Everything, one keystroke away

Ctrl+P (⌘P) to any file, Ctrl+K (⌘K) to any setting or command.

AI when you ask

Your Claude or ChatGPT plan, an API key, a model on your own computer, or none at all. It never changes code without showing you the change.

Keys your hands know

VS Code, JetBrains, Sublime Text, Zed, or Vim.

Never lose work

Unsaved changes survive a crash, every save is kept for a month, and files changed on disk are never silently written over.

What it does

Code intelligence for Rust, Python, TypeScript, Go, C, C++ and more; Markdown with a live preview; run, test and debug without leaving the code.
